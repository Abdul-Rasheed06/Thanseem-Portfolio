# Thanseemnasar - Professional Portfolio

This is the complete source code for the personal portfolio website of **Thanseemnasar**, MBA Professional in Human Resources, Business Development, and Operations Management.

## Structure
- `index.html`: Main landing page containing Hero, About, Experience, Skills, and Contact sections.
- `css/style.css`: Custom CSS styles and overrides.
- `js/main.js`: Interactive elements (mobile menu toggling).

## Quick Start
1. Extract the ZIP file.
2. Open `index.html` in any modern web browser or host it on Netlify, Vercel, or GitHub Pages.
